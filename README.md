# JavaScript Clock ⏰

A simple and interactive Clock project built using HTML, CSS, and JavaScript. This project demonstrates how to display and update time dynamically using JavaScript.

## 🚀 Live Demo

[View Clock Project](https://github.com/Ishan13-dev/Clock)

## 📌 About the Project

This project is created to practice JavaScript fundamentals by building a clock that displays the current time.

It demonstrates JavaScript date and time functionality, DOM manipulation, and dynamic webpage updates.

## ✨ Features

- Real-time clock functionality.
- Automatic time updates.
- Dynamic time display using JavaScript.
- Simple and clean user interface.
- HTML and CSS-based layout.
- Beginner-friendly JavaScript implementation.

## 🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and layout.
- JavaScript – Clock functionality and dynamic updates.

## ⚙️ How to Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/Ishan13-dev/Clock.git
```

**2. Navigate to the project folder**

```bash
cd Clock
```

**3. Run the project**

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
